# Negotiation Inc — static site

The landing page, The Eight Exits course, The Desk underwriting worksheet, and
the arcade. No server, no build step: every file here is served as-is.

- `index.html` — the landing page
- `desk.html` — the underwriting worksheet
- `exits.html` — the course
- `office.html` — your desk: sign-in and dashboard
- `plans.html` — the feature ladder, every row marked live or in build
- `arcade.html` — the arcade **floor** (cabinet select)
- `comp-run.html` — Cabinet 01, the idle game
- `exit-drill.html` — Cabinet 03, the sixty-second drill
- `priors.js` — ZIP-level value and rent priors, US Census ACS 5-yr 2023
- `art/`, `og/`, `card/`, `d/`, `fonts/` — pixel art, link previews, share
  cards, deed stubs, self-hosted typefaces

Everything is generated by `publish.mjs` in the working tree; edit there, not
here. Every figure the software prints says where it came from — the
calibration and its sources are documented alongside the source.
