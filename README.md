# Negotiation Inc — static site

The landing page, The Eight Exits course, The Desk underwriting worksheet, and the arcade.
No server, no build step: every file here is served as-is.

- `index.html` — the landing page
- `desk.html` — the underwriting worksheet
- `exits.html` — the course
- `arcade.html` — the game
- `priors.js` — ZIP-level market medians (US Census ACS 5-year)
- `d/`, `og/`, `card/` — share stubs and preview images
